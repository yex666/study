# F06: i18n — 国际化

> **模块路径**: `src/chrys/foundation/i18n/`
> **核心文件**: `messages.py`, `localizer.py`, `catalogs.py`, `formatting.py`
> **一句话**: 让 UI 能显示中文、英文等不同语言，同时保证类型安全和模板正确性。

---

## 这是什么？

一个**类型安全的国际化系统**。用 `msg()` 定义可翻译的消息，运行时根据用户的 locale 选择对应的翻译。

```python
from chrys.foundation.i18n import msg

# 定义消息（在模块级别）
GREETING = msg("app.greeting", fallback="Hello, {name}!")

# 使用时绑定参数
rendered = localizer.render(GREETING.bind(name="Alice"))
# → "你好，Alice！" (中文) 或 "Hello, Alice!" (英文)
```

---

## 为什么需要？

### 如果不做会怎样？

到处是硬编码的字符串：

```python
# ❌ 硬编码字符串
def show_error(error_code):
    if error_code == "auth_failed":
        print("Authentication failed")  # ← 只有英文
    elif error_code == "rate_limited":
        print("Rate limited")           # ← 无法本地化
```

**问题**：
1. 无法支持多语言
2. 改文案要改代码
3. 无法提取翻译给翻译人员

### 或者用简单的字典映射

```python
# ❌ 简单的字典映射
TRANSLATIONS = {
    "en": {"greeting": "Hello, {name}!"},
    "zh": {"greeting": "你好，{name}！"},
}

def translate(key, locale, **args):
    template = TRANSLATIONS.get(locale, {}).get(key, key)
    return template.format(**args)
```

**问题**：
1. 没有类型检查（参数名拼错不会报错）
2. 不支持复数形式（"1 file" vs "2 files"）
3. 翻译缺失时静默返回 key（用户看到 "greeting"）
4. 无法验证翻译模板的正确性

### 用了 Chrys 的 i18n 之后

```python
# ✅ 类型安全 + 自动验证
GREETING = msg(
    "app.greeting",
    fallback="Hello, {name}!",
    plural_fallback="{count} greetings!",  # 支持复数
)

# 编译时检查（通过 scripts/i18n.py extract）
# 运行时验证（翻译模板必须匹配原始定义的参数）

rendered = localizer.render(GREETING.bind(name="Alice", count=1))
```

## 核心设计：四个关键决策

### 决策 1: 两阶段分离（定义 vs 引用）

```python
@dataclass(frozen=True, slots=True, kw_only=True)
class MessageDef:
    """One immutable, extractable semantic message definition."""
    
    key: str                    # "app.greeting"
    fallback: str               # "Hello, {name}!"
    plural_fallback: str | None # "{count} greetings!" (可选)
    multiline: bool = False

@dataclass(frozen=True, slots=True, kw_only=True)
class MessageRef:
    """One immutable occurrence of a semantic message definition."""
    
    definition: MessageDef
    args: tuple[tuple[str, MessageArg], ...]  # (("name", "Alice"),)
    count: int | None = None                  # 复数计数
```

**为什么？**

- **MessageDef**：定义一次，全局共享（模块级常量）
- **MessageRef**：每次使用创建新实例，绑定具体参数

这样翻译提取工具可以扫描所有 `MessageDef`，生成 `.pot` 文件给翻译人员。

---

### 决策 2: 强制使用 msg() 构造

```python
_CONSTRUCTION_TOKEN = object()  # 私有令牌

@dataclass(frozen=True, slots=True, kw_only=True)
class MessageDef:
    _token: InitVar[object]  # 必须是 _CONSTRUCTION_TOKEN
    
    def __init_subclass__(cls, **kwargs: object) -> None:
        raise TypeError("MessageDef cannot be subclassed.")
    
    def __post_init__(self, _token: object) -> None:
        if _token is not _CONSTRUCTION_TOKEN:
            raise TypeError("MessageDef values must be constructed with msg().")
        _validate_definition(self)

def msg(key: str, *, fallback: str, ...) -> MessageDef:
    """Declare one extractable semantic message definition."""
    return MessageDef(
        _token=_CONSTRUCTION_TOKEN,
        key=key,
        fallback=fallback,
        ...
    )
```

**为什么？**

- 防止用户直接 `MessageDef(key=..., fallback=...)`（绕过验证）
- 确保所有消息都经过 `_validate_definition()` 检查
- `_CONSTRUCTION_TOKEN` 是私有的，外部无法获取

---

### 决策 3: 翻译模板验证

```python
def render(self, reference: MessageRef) -> str:
    """Render a bound semantic message through the active locale bundle."""
    
    # 从 catalog 查找翻译
    template = translations.gettext(definition.key)
    
    # 验证翻译模板的参数是否匹配原始定义
    validator = bundle.validate_template
    names = validator(template, definition.multiline)
    
    if names is None:
        logger.warning("Invalid i18n catalog entry; using English fallback.")
        return format_message(reference)  # 回退到英文
    
    parameters = _render_arguments(reference)
    parameter_names = set(parameters)
    
    # 检查参数集合是否一致
    if names - {"count"} != parameter_names - {"count"}:
        logger.warning("Invalid i18n catalog entry; using English fallback.")
        return format_message(reference)
    
    # 格式化翻译
    translated = template.format_map(parameters)
    
    if not has_visible_content(translated):
        logger.warning("Invalid i18n catalog entry; using English fallback.")
        return format_message(reference)
    
    return translated
```

**为什么？**

翻译人员可能：
- 漏掉参数（`"Hello!"` 而不是 `"Hello, {name}!"`）
- 多加参数（`"Hello, {name} {age}!"`）
- 写成空字符串

这些错误会在运行时检测到，自动回退到英文 fallback，并记录警告日志。

### 决策 4: 原子性 locale 切换

```python
def switch_locale(self, requested_locale: str) -> CatalogLoadWarning | None:
    """Build and atomically install a locale bundle, retaining state on failure."""
    
    prior = self._state
    effective_locale = normalize_locale(requested_locale)
    
    # 如果请求的 locale 和当前一样，直接返回
    if effective_locale == prior.bundle.locale_name:
        self._state = _LocalizerState(requested_locale=requested_locale, bundle=prior.bundle)
        return None
    
    # 切换到英文
    if effective_locale == ENGLISH_LOCALE:
        self._state = _LocalizerState(requested_locale=requested_locale, bundle=_ENGLISH_BUNDLE)
        return None
    
    # 尝试加载新的 catalog
    try:
        bundle = self._build_bundle(effective_locale)
    except CatalogLoadError:
        logger.warning("Requested i18n catalog unavailable; keeping active locale.")
        return CatalogLoadWarning(requested_locale=requested_locale)
    
    # 原子性替换状态
    self._state = _LocalizerState(requested_locale=requested_locale, bundle=bundle)
    return None
```

**为什么？**

如果新的 catalog 加载失败（文件不存在、格式错误），保留当前的 locale，不会导致 UI 显示混乱。

### MessageDef 定义

```python
@dataclass(frozen=True, slots=True, kw_only=True)
class MessageDef:
    """One immutable, extractable semantic message definition."""
    
    _token: InitVar[object]
    key: str                    # "app.greeting" (必须是小写字母+点号)
    fallback: str               # "Hello, {name}!" (英文模板)
    plural_fallback: str | None # "{count} greetings!" (复数模板，可选)
    multiline: bool = False     # 是否允许多行
    
    def bind(self, *, count: int | None = None, **args: MessageArg) -> MessageRef:
        """Bind one occurrence's named arguments and optional plural count."""
        
        # 检查 count 的使用
        if count is None:
            resolved_count = None
        elif self.plural_fallback is None:
            raise ValueError("count is forbidden for a singular message definition.")
        elif type(count) is not int:
            raise TypeError("count must be exactly int.")
        else:
            resolved_count = count
        
        return MessageRef(
            _token=_CONSTRUCTION_TOKEN,
            definition=self,
            args=tuple(sorted(args.items())),  # 排序保证确定性
            count=resolved_count,
        )
```

### Localizer 渲染

```python
class Localizer:
    """Render MessageRef values through one atomically replaceable bundle."""
    
    def __init__(self, requested_locale: str, *, catalog_root: CatalogRoot | None = None) -> None:
        self._catalog_root = catalog_root
        self._state = _LocalizerState(requested_locale=requested_locale, bundle=_ENGLISH_BUNDLE)
        
        # 尝试加载请求的 locale
        effective_locale = normalize_locale(requested_locale)
        if effective_locale == ENGLISH_LOCALE:
            return
        
        try:
            bundle = self._build_bundle(effective_locale)
        except CatalogLoadError:
            logger.warning("Requested i18n catalog unavailable; using English.")
            self._state = _LocalizerState(
                requested_locale=requested_locale,
                bundle=_ENGLISH_BUNDLE,
                first_load_warning=CatalogLoadWarning(requested_locale=requested_locale),
            )
            return
        
        self._state = _LocalizerState(requested_locale=requested_locale, bundle=bundle)
    
    def render(self, reference: MessageRef) -> str:
        """Render a bound semantic message through the active locale bundle."""
        
        bundle = self._state.bundle
        translations = bundle.translations
        
        # 英文直接格式化
        if translations is None:
            return format_message(reference)
        
        definition = reference.definition
        
        try:
            # 查找翻译
            if reference.count is None:
                template = translations.gettext(definition.key)
            else:
                plural_id = f"{definition.key}#plural"
                template = translations.ngettext(definition.key, plural_id, reference.count)
        
        except LookupError, OSError, TypeError, ValueError, ZeroDivisionError:
            logger.warning("Invalid i18n catalog lookup; using English fallback.")
            return format_message(reference)
        
        # 检查是否是未翻译的 key
        if _formatting._normalized_lookup_candidate(template) in {definition.key}:
            logger.debug("Missing i18n catalog entry; using English fallback.")
            return format_message(reference)
        
        # 验证翻译模板
        validator = bundle.validate_template
        if validator:
            names = validator(template, definition.multiline)
            if names is None:
                logger.warning("Invalid i18n catalog entry; using English fallback.")
                return format_message(reference)
            
            parameters = _render_arguments(reference)
            parameter_names = set(parameters)
            
            # 检查参数集合是否一致
            if names - {"count"} != parameter_names - {"count"}:
                logger.warning("Invalid i18n catalog entry; using English fallback.")
                return format_message(reference)
        
        # 格式化翻译
        try:
            translated = template.format_map(parameters)
        except KeyError, ValueError:
            logger.warning("Invalid i18n catalog entry; using English fallback.")
            return format_message(reference)
        
        # 检查是否有可见内容
        if not has_visible_content(translated):
            logger.warning("Invalid i18n catalog entry; using English fallback.")
            return format_message(reference)
        
        return translated
```

### 翻译工作流

```bash
# 1. 提取所有 msg() 定义到 .pot 文件
uv run python scripts/i18n.py extract

# 2. 更新 .po 文件（添加新消息，标记过时消息）
uv run python scripts/i18n.py update

# 3. 翻译人员编辑 locales/zh-Hans/LC_MESSAGES/chrys.po

# 4. 编译 .po 到 .mo（二进制格式，gettext 使用）
uv run python scripts/i18n.py compile

# 5. 检查翻译完整性
uv run python scripts/i18n.py check
```

## 实际使用场景

### 场景 1: 定义消息

```python
# src/chrys/app/tui/screens/main/screen.py

from chrys.foundation.i18n import msg

# 模块级常量
WELCOME_MESSAGE = msg(
    "tui.welcome",
    fallback="Welcome to Chrys!",
)

ERROR_AUTH_FAILED = msg(
    "error.auth_failed",
    fallback="Authentication failed. Please check your API key.",
)

FILES_CHANGED = msg(
    "status.files_changed",
    fallback="{count} file changed",
    plural_fallback="{count} files changed",
)
```

### 场景 2: 渲染消息

```python
class MainScreen:
    async def on_mount(self):
        # 简单消息
        self.notify(self.localizer.render(WELCOME_MESSAGE))
        
        # 带参数的消息
        self.notify(self.localizer.render(ERROR_AUTH_FAILED))
        
        # 复数消息
        count = len(changed_files)
        message = FILES_CHANGED.bind(count=count)
        self.notify(self.localizer.render(message))
        # → "1 file changed" 或 "5 files changed"
```

### 场景 3: 切换 locale

```python
# 用户在设置中选择中文
await settings.update("ui.locale", "zh-Hans")

# TUI 响应 locale 变化
async def on_locale_changed(new_locale: str):
    warning = self.localizer.switch_locale(new_locale)
    
    if warning:
        # 翻译文件不可用，保持当前 locale
        self.notify(f"Failed to load {new_locale}, keeping current locale.")
    else:
        # 成功切换，重新渲染所有文本
        await self.recompose()
```

## 如果你要自己实现

### 最小版本（30 行）

```python
import gettext
from dataclasses import dataclass

@dataclass(frozen=True)
class SimpleMessageDef:
    key: str
    fallback: str

@dataclass(frozen=True)
class SimpleMessageRef:
    definition: SimpleMessageDef
    args: dict[str, str]

def simple_msg(key: str, fallback: str) -> SimpleMessageDef:
    return SimpleMessageDef(key=key, fallback=fallback)

class SimpleLocalizer:
    def __init__(self, locale: str):
        self.locale = locale
        # 加载 gettext catalog
        self.translations = gettext.translation("myapp", languages=[locale])
    
    def render(self, ref: SimpleMessageRef) -> str:
        template = self.translations.gettext(ref.definition.key)
        
        # 如果没找到翻译，用 fallback
        if template == ref.definition.key:
            template = ref.definition.fallback
        
        return template.format(**ref.args)
```
